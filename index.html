STANDARD OPERATING BRIEF // 05

BRIEF TEMPLATE GUIDE — คู่มือและเทมเพลตมาตรฐานการบรีฟงานทีม

โครงสร้างการบรีฟงานสไตล์ Minimal Editorial เพื่อให้แมทใช้สั่งงานและตรวจเช็คบรีฟของ แม็ค, โอ๊ค, แพ็ค, ปลา และลูกตาล ได้ครบทุกประเด็นโดยไม่ตกหล่น กดปุ่ม "สร้างงานด้วยเทมเพลตนี้" เพื่อเปิดหน้าต่างมอบหมายงานพร้อมกรอกโครงสร้างบรีฟให้อัตโนมัติ

RULE 01 // ADVANCE BUFFER
ตั้งเตือนล่วงหน้า 3–5 วันเสมอสำหรับงานกราฟิก

งานบรีฟ Artwork (โอ๊ค), ปกคลิป (ปลา) และภาพโพสต์ขาย (ลูกตาล) ควรมีเวลาตรวจดราฟต์แรกก่อนวันโพสต์จริงอย่างน้อย 3 วัน

RULE 02 // SINGLE SOURCE LINK
แนบลิงก์ไฟล์อ้างอิงในการ์ดงานทุกครั้ง

แนบลิงก์ Canva, Google Drive หรือ Sheet งบประมาณไว้ในช่อง Brief Links เพื่อให้แมทและแม็คกดตรวจจากมือถือได้ทันที

RULE 03 // DIRECTOR GATEWAY
ผ่านการอนุมัติงบจากแม็คก่อนเบิกจ่ายจริง

เมื่อแมทสรุปแผนกลยุทธ์เสร็จ ให้ตั้งสถานะเป็น "รอแม็คคุยผู้ใหญ่/อนุมัติงบ" ก่อนส่งต่อให้แพ็คทำเรื่องเบิกจ่าย

สถานะ: ปิดอยู่

จัดการสิทธิ์ผู้ใช้ (เฉพาะผู้ดูแล)
ผู้ดูแล = ทำได้ทุกอย่าง • ทีมงาน = ปรับสถานะ/ติ๊กเสร็จได้เฉพาะงานที่มอบหมายให้ตัวเอง (ต้องเลือกว่าอีเมลนี้คือใคร) • ดูอย่างเดียว = ดูได้ แก้ไม่ได้
วิธีตั้งค่า Firebase (ทำครั้งเดียว ฟรี)
1. console.firebase.google.com → Add project
2. Build → Realtime Database → Create (Singapore, locked mode) → แท็บ Rules วางโค้ด Rules ด้านล่าง → Publish
3. Build → Authentication → Sign-in method เปิด Google และ Email/Password (ติ๊ก Email link) → แท็บ Settings → Authorized domains เพิ่ม ชื่อผู้ใช้.github.io
4. Project settings → Your apps → เพิ่มเว็บแอป (</>) → คัดลอกก้อน firebaseConfig มาวางด้านล่าง → บันทึก
5. เปิดเว็บแล้วเข้าสู่ระบบ — คนแรกที่เข้าสู่ระบบจะเป็นผู้ดูแลอัตโนมัติ (ให้แมทเข้าเป็นคนแรกทันที) จากนั้นเพิ่มอีเมลทีมในส่วนจัดการสิทธิ์ แล้วส่งลิงก์เชิญให้ทีม
Rules ของ Realtime Database (บังคับสิทธิ์ที่ฝั่งเซิร์ฟเวอร์)
